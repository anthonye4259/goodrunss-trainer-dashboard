## 📱 **MOBILE APP INTEGRATION:**

### **Example: Complete User Flow**

```typescript
// 1. Guest opens app (no login)
const { sessionToken } = await createGuestSession();

// 2. Quick onboarding
await saveOnboardingPrefs({
  fitnessGoals: ['weight_loss', 'strength'],
  sports: ['tennis', 'yoga'],
  location: { lat, lng }
});

// 3. Get personalized feed
const { content } = await getPersonalizedFeed(sessionToken);

// 4. Ask G.I.A. for advice (free user: 3/day)
const access = await checkSubscriptionAccess(userId, 'gia_query');
if (access.hasAccess) {
  const { response } = await askGIA({
    question: "How do I improve my tennis serve?",
    sport: "tennis"
  });
}

// 5. Try to book AI persona (requires subscription)
const access2 = await checkSubscriptionAccess(userId, 'ai_persona_session');
if (!access2.hasAccess) {
  showUpgradeModal('basic'); // $4.99/mo
}

// 6. Subscribe to Basic
const { checkoutUrl } = await subscribe({
  planName: 'basic',
  billingCycle: 'monthly'
});
openURL(checkoutUrl);

// 7. Book real trainer (10% off for Pro/Elite)
const discount = await getBookingDiscount(userId); // 0% for Basic, 10% for Pro
const finalPrice = trainerPrice * (1 - discount / 100);

// 8. Get environmental recommendations
const { weather, airQuality } = await getEnvironmentalData(lat, lng);
if (weather.isGoodForTennis) {
  showNotification("Perfect weather for outdoor tennis today!");
}
```
