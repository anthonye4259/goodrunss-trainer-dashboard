⚡ 5-MINUTE SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ RUN DATABASE MIGRATION
   → Open Supabase SQL Editor
   → Copy/paste: prisma/migrations/add_public_booking_system.sql
   → Click "Run"

2️⃣ CONFIGURE STRIPE WEBHOOK
   → Stripe Dashboard → Webhooks → Add endpoint
   → URL: https://yourdomain.com/api/webhooks/booking-payment
   → Events: checkout.session.completed, checkout.session.expired
   → Copy webhook secret
   → Add to .env: STRIPE_WEBHOOK_SECRET=whsec_...

3️⃣ TEST THE SYSTEM
   → Login as trainer → /dashboard/bookings
   → Create booking settings (slug, session types, availability)
   → Copy booking link
   → Test booking (Stripe test card: 4242 4242 4242 4242)
   → Verify confirmation in dashboard

  2. Prevent double-bookings
  3. Stripe payment processing
  4. Webhook confirms booking

🔧 KEY API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TRAINER (Auth Required):
  GET    /api/booking-settings           → Fetch settings
  POST   /api/booking-settings           → Create/update settings
  GET    /api/booking-availability       → Fetch availability
  POST   /api/booking-availability       → Add time slot
  DELETE /api/booking-availability?id=x  → Remove slot
  GET    /api/my-bookings                → View bookings
  PATCH  /api/my-bookings?id=x           → Update booking

PUBLIC (No Auth):
  GET    /api/book/[slug]/info           → Trainer + session types
  GET    /api/book/[slug]/slots          → Available time slots
  POST   /api/book/[slug]/book           → Create booking + payment

WEBHOOKS:
  POST   /api/webhooks/booking-payment   → Stripe payment webhook
